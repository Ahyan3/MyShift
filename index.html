              Set up Supabase in 5 minutes (free)
              1. Create a free project at supabase.com.
              2. Open SQL Editor, paste the SQL below and run it.
              3. Go to Project Settings → API and copy the Project URL and the anon public key.
              4. Paste them above, keep the table name shiftline_state, then press Test connection.
              5. Press Push to cloud. On your other device, open this file, enter the same URL, key and sync key, then press Pull from cloud.
              
          
              
          
              The sync key is the row name for your data — treat it like a password and use the same key on every device. With this policy the table is reachable by anyone who has your anon key, so a long random sync key matters. For stronger protection, enable Supabase Auth and change the policy to auth.uid() = owner.
